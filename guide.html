GUIDE

Spring Music Festival 2026を安全に、そして思いっきり楽しんでいただくための情報をまとめました。
ご来場前に必ずご確認ください。

必須の持ち物

  • チケット(印刷したもの、またはスマートフォンに購入確認メールを保存)
  • 身分証明書(年齢確認が必要な場合があります)
  • 現金(会場内でキャッシュレス決済も可能ですが、念のため)
  • スマートフォン(連絡用、最新情報確認用)

おすすめの持ち物

日差し対策

  • 日焼け止め / 帽子・キャップ / サングラス

雨天対策

  • レインコート・ポンチョ（傘は使用禁止です）
  • 長靴またはレインシューズ / タオル

その他

  • レジャーシート / 飲み物 / モバイルバッテリー
  • ウェットティッシュ / ゴミ袋 / 着替え / 常備薬 / 耳栓

違反が確認された場合は、ご退場いただく場合がございます。

持ち込み禁止物

  • 危険物(刃物、花火、スプレー缶など)
  • ビン・カン類 / アルコール類の持ち込み
  • テント・タープ / 大型の荷物(キャリーケースなど)
  • 椅子・脚立 / 長い傘・日傘

禁止行為

  • ペット同伴 / 指定場所以外での喫煙
  • 録音・録画 / 自撮り棒・三脚の使用
  • 無許可の物販 / 場所取りのための放置
  • モッシュ、ダイブ等の危険行為 / 他のお客様への迷惑行為

開催基準

  • 小雨：決行
  • 荒天(台風、雷雨など)：中止の場合あり

発表方法

前日18:00に公式サイト、公式X、Instagram、メールにてお知らせします。

中止の場合

チケット代金の払い戻しを実施いたします。交通費・宿泊費の補償はできません。

服装について
動きやすく温度調節ができる服装、スニーカーを推奨します。
熱中症対策
こまめな水分補給を。会場内に救護テントがございます。
貴重品の管理
各自で管理をお願いします。盗難・紛失の責任は負いかねます。
お子様連れの方へ
授乳室・おむつ交換スペースをご用意しています。
  • 音楽を楽しむために：後ろの方の視界を遮らない配慮をお願いします。
  • 周りの方への配慮：通路を塞がない、割り込みをしない。
  • 体調管理：無理をせず、疲れたら休憩を。

ご不明な点がございましたら、お気軽にお問い合わせください。
